# FormatConverter

Небольшой веб-сервис на Spring Boot для работы с PDF:

- **Изображение → PDF** — JPEG, PNG, GIF, BMP или TIFF превращается в одностраничный PDF.
  Изображение вписывается в страницу A4 с сохранением пропорций (для «горизонтальных»
  картинок страница альбомная).
- **Объединение PDF** — несколько PDF-файлов склеиваются в один, страницы идут в порядке файлов.

## Запуск

Нужна Java 21.

```bash
./gradlew bootRun
```

Интерфейс откроется на <http://localhost:8080/>.

Тесты:

```bash
./gradlew test
```

## HTTP API

| Метод и путь   | Параметры (multipart/form-data) | Ответ                                                  |
|----------------|---------------------------------|--------------------------------------------------------|
| `POST /toPdf`  | `file` — изображение            | `application/pdf`, имя файла как у исходного, но `.pdf` |
| `POST /merge`  | `files` — два и более PDF       | `application/pdf`, `merged.pdf`                        |

Ошибки возвращаются в формате [RFC 9457 Problem Details](https://www.rfc-editor.org/rfc/rfc9457)
(`application/problem+json`), человекочитаемое сообщение — в поле `detail`:

- `400` — файл пустой, не является изображением/PDF, повреждён или защищён паролем;
- `413` — превышен лимит размера загрузки.

Пример:

```bash
curl -f -OJ -F file=@photo.jpg http://localhost:8080/toPdf
curl -f -OJ -F files=@a.pdf -F files=@b.pdf http://localhost:8080/merge
```

## Настройки

| Переменная окружения | По умолчанию | Описание                                          |
|----------------------|--------------|---------------------------------------------------|
| `MAX_FILE_SIZE`      | `50MB`       | Максимальный размер одного загружаемого файла     |
| `MAX_REQUEST_SIZE`   | `200MB`      | Максимальный суммарный размер файлов в запросе    |

Файлы обрабатываются целиком в памяти, поэтому при увеличении лимитов стоит увеличить и heap JVM.
